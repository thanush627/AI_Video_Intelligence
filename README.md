# Agentic Multimodal Retrieval for Long-Horizon Spatiotemporal Event Grounding

## Overview

This project is a production-grade AI Video Intelligence Platform capable of understanding uploaded videos and live RTSP CCTV streams using state-of-the-art Computer Vision, Vision-Language Models, Vector Databases, and Agentic AI.

The platform supports natural language and multilingual voice queries to retrieve spatiotemporal events from long-duration videos with very low retrieval latency.

---

# Features

- Upload videos
- Live RTSP CCTV support
- Adaptive frame extraction
- YOLOv8 object detection
- ByteTrack multi-object tracking
- Vision-Language understanding
- Object, color, attribute and action recognition
- CLIP embedding generation
- ChromaDB vector retrieval
- PostgreSQL metadata filtering
- LangGraph Agentic Retrieval
- Timestamp localization
- Automatic FFmpeg clip generation
- FastAPI backend
- React dashboard
- Flutter mobile application
- Docker deployment
- AWS deployment
- Monitoring with Prometheus and Grafana
